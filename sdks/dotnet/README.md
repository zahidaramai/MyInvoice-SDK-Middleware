# MyInvois.Sdk - the C# library for the KLCubeLHDN MyInvois Middleware API

API middleware gateway for Malaysia's MyInvois e-invoicing system (LHDN).

**Version:** 1.1.1

## Features
- 4 Submission Endpoints (Consolidate, JustSave, Buyer, Personal)
- JWT Authentication with Access & Refresh Tokens
- User/Role/Company Management
- Document Operations (List, Status, PDF, Cancel)
- Digital Signing v1.1 (XAdES signatures)
- Background Status Polling
